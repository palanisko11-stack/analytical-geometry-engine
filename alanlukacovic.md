# ⚡ Unified Analytical Engine (v2.0)

**The first real-time bridge between CAD precision and SVG vector flexibility.**

Traditional 3D engines are built on polygons. This engine is built on **pure mathematics**. By using Signed Distance Fields (SDFs) and B-Rep logic, we achieve infinite precision with minimal data overhead.

## 🌟 Key Features
*   **Infinite Detail:** Zoom in forever. No pixels, no triangles—just perfect analytical curves.
*   **Semantic Control:** Define your scene via human-readable JSON, not heavy binary blobs[cite: 1, 2].
*   **Zero Loading Time:** The entire "Workbench" is a single lightweight HTML file.
*   **Dynamic Intent:** Switch between "Engrave" and "Emboss" in real-time without recalculating UV maps[cite: 1, 2].

## 🛠 How to use
1. Open `Unified_Engine_v2.html` in any modern browser.
2. Use the **Engine Parameters** panel to manipulate geometry.
3. Observe the **Live JSON State** — this is what drives the engine[cite: 1].
